# ترب‌یار | Torob Yar

**از «چی بخرم؟» تا رسیدن به فروشگاه؛ یک همراه فارسی برای خرید حضوری.**

ترب‌یار به کاربر کمک می‌کند مدل مناسب را پیدا کند، محصول و فروشنده‌ها را مقایسه کند، ابهام‌های مراجعه را ببیند و در صورت بسته بودن یا بی‌پاسخ ماندن فروشگاه، گزینهٔ جایگزین پیدا کند.

نمونهٔ مستقل برای [چالش ترب در استارکوچ](https://starcoach.ir/hackathon/agentic-ai/challenges/7)؛ سرویس رسمی ترب نیست. رابط با زبان بصری ترب، راست‌به‌چپ و واکنش‌گرا طراحی شده است.

## اجرای پروژه

نیازمندی‌ها: Node.js 22+ و Python 3.10+. وابستگی npm لازم نیست.

```sh
git clone https://github.com/ashkanhfz/torob-yar.git
cd torob-yar
python scripts/setup_data.py
npm start
```

سپس `http://localhost:3000` را باز کنید.

دیتاست داخل مخزن بازنشر نشده است. اسکریپت، ZIP رسمی را دریافت می‌کند و داده‌ها را برای اجرا بازسازی و بررسی می‌کند. اگر شبکه دانلود مستقیم را نپذیرفت، [ZIP رسمی](https://startech.s3.ir-central1.arvanstorage.ir/starcoach-dataset-v16-cap300-csv.zip?versionId=) را با مرورگر دانلود کنید:

```sh
python scripts/setup_data.py --archive /path/to/starcoach-dataset-v16-cap300-csv.zip
```

ورودی رسمی شامل **۲۲۵٬۹۰۳ محصول، ۳۳۱٬۵۰۶ آفر و ۶٬۴۷۶ فروشگاه** است. داده‌های تولیدشده و فایل‌های محیطی در Git نادیده گرفته می‌شوند.

## قابلیت‌های موجود

- راهنمای مرحله‌ای انتخاب مدل با دسته و بودجه؛ گفتگوی اختیاری با fallback شفاف.
- جستجو در کل دیتاست، اولویت دادن به خود محصول در برابر لوازم جانبی و مقایسهٔ حداکثر سه مدل.
- فروشگاه‌های یکتا بر اساس آفر واقعی محصول؛ قیمت، فاصلهٔ مستقیم، ساعت مراجعه و شرایط پرداخت کنار هم.
- فیلتر اعتبار حضوری تنها برای اطلاعات صریح و منطبق با محصول و بازهٔ قیمت.
- تفکیک قیمت تاریخی، تاریخ تغییر قیمت، موجودی نامعلوم و یادداشت شخصی کاربر.
- کنارگذاشتن فروشگاه بسته/بی‌پاسخ با حفظ فیلترها و پیشنهاد جایگزین.
- طبقه و واحد از آدرس موجود، پیوند نقشه و گوگل، برنامهٔ خرید محلی و دریافت فایل برنامه.

## وضعیت اتصال‌ها

|بخش|وضعیت|
|---|---|
|جستجو، مقایسه، فیلتر و برنامهٔ خرید|قابل اجرا پس از آماده‌سازی دیتاست|
|مدل زبانی آنلاین|اختیاری؛ نیازمند `AI_BASE_URL`، `AI_API_KEY` و `AI_MODEL` در سرور|
|تماس واقعی|adapter اولیه موجود؛ سرویس تماس و شمارهٔ معتبر متصل نشده‌اند|
|موجودی زنده و نتیجهٔ تأییدشدهٔ تماس|پیاده نشده؛ callback و ذخیرهٔ نتیجه لازم است|
|جستجوی خودکار گوگل|پیاده نشده؛ پیوند بررسی آدرس موجود است|
|لیارا|Dockerfile و تنظیم پورت آماده؛ انتشار نیازمند حساب میزبان است|

**تمام تلفن‌های دیتاست جعلی‌اند.** با آن‌ها تماس گرفته نمی‌شود. بیشتر نام فروشگاه‌ها نیز ساختگی‌اند. قیمت تاریخی و برنامهٔ ساعت کاری، تضمین قیمت امروز یا موجودی نیستند. نبود اطلاعات با «تأییدشده» جایگزین نمی‌شود.

## تست‌ها

```sh
npm run check
npm run test:unit
# پس از آماده‌سازی دیتاست:
npm test
python scripts/verify_data.py
```

CI، بررسی نحوی و تست‌های واحدِ بدون دیتاست را اجرا می‌کند. تست‌های یکپارچهٔ بازیابی واقعی و بررسی تمام روابط داده باید پس از آماده‌سازی دیتاست اجرا شوند؛ عبور CI به معنی تأیید سرویس تماس یا مدل خارجی نیست.

## استقرار

برای اجرای محلی کافی است `npm start` را اجرا کنید. برای Docker، ابتدا داده‌ها را آماده و سپس image را بسازید. فایل `.env.example` نام تنظیمات لازم را دارد؛ کلیدها در محیط میزبان قرار می‌گیرند و وارد فرانت نمی‌شوند.

```sh
docker build -t torob-yar .
docker run --rm -p 3000:3000 --env-file .env torob-yar
```

فایل `liara.json` پورت ۳۰۰۰ را مشخص می‌کند. خروجی static فقط رابط و داده‌ها را اجرا می‌کند؛ برای endpointهای مدل و تماس، سرور Node لازم است.

## مسیریابی و ظاهر جدید

[راهنمای راه‌اندازی OSRM محلی](docs/ROUTING.fa.md) شامل آماده‌سازی نقشهٔ ایران، اجرای محدود به localhost و اتصال `OSRM_BASE_URL` است. مسیریابی خودرو و برنامهٔ چند فروشگاه بدون مدل زبانی انجام می‌شود.

[جزئیات امکانات و محدودیت‌ها](FEATURES.md) وضعیت گزارش‌های مدیریت، جستجوی ایندکس‌شده، سابقهٔ واقعی قیمت، فونت و اتصال سرویس‌ها را توضیح می‌دهد.

[راه‌اندازی Elasticsearch محلی](docs/SEARCH.fa.md) برای جستجوی واقعی روی همهٔ محصولات با fallback به inverted index در دسترس است.
