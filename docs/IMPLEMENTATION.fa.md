# ترب‌یار — همراه خرید حضوری

رابط فارسی و راست‌به‌چپ با زبان بصری ترب. این پروژه نمونهٔ مستقل چالش است و سرویس رسمی ترب نیست.

## اجرای سریع

به Node.js نسخهٔ ۲۲ یا جدیدتر نیاز است. هیچ وابستگی npm لازم نیست.

```sh
npm start
```

آدرس: `http://localhost:3000`. جستجو، مقایسه، فیلتر و برنامهٔ خرید بدون کلید سرویس خارجی کار می‌کنند. فایل HTML را مستقیم با file:// باز نکنید؛ داده‌ها با fetch بارگیری می‌شوند.

## آنچه پیاده‌سازی شده

- کل دیتاست رسمی: ۲۲۵٬۹۰۳ محصول، ۳۳۱٬۵۰۶ آفر و ۶٬۴۷۶ فروشگاه؛ اتصال بر اساس شناسه، نه دستهٔ فعالیت فروشنده.
- جستجوی فارسی با یکسان‌سازی ی/ک عربی، بودجه و ترتیب قیمت؛ نمایش حداکثر ۱۶۰ تطبیق برای هر جستجو با اعلام شفاف این محدودیت.
- راهنمای مرحله‌ای نیاز، کاربرد و بودجه؛ مقایسهٔ حداکثر ۳ مدل بر اساس مشخصات واقعی.
- رتبه‌بندی قابل توضیح فروشگاه‌ها: ۴۵٪ نسبت قیمت به کمینه، ۳۵٪ فاصله و ۲۰٪ ساعت مراجعه. این وزن‌ها انتخاب طراحی‌اند، نه ادعای دقت علمی.
- فاصلهٔ مستقیم با فرمول هاورساین، مبدأ محله یا GPS اختیاری؛ هیچ زمان سفر تخمینی ساختگی نشان داده نمی‌شود.
- ساعت کاری در منطقهٔ زمانی تهران، شامل شیفت عبوری از نیمه‌شب؛ وضعیت زندهٔ فروشگاه ادعا نمی‌شود.
- اعتبار حضوری تنها برای `channel=in_person` و رعایت بازهٔ قیمت و دستهٔ اعلام‌شده. channel نامشخص به معنی پذیرش حضوری نیست.
- تفکیک قیمت تاریخی، تاریخ تغییر قیمت، موجودی نامعلوم و یادداشت شخصی کاربر.
- کنارگذاشتن فروشگاه بسته/بی‌پاسخ و مرتب‌سازی مجدد جایگزین‌های واقعی همان محصول؛ جستجوی مدل مشابه در نبود جایگزین.
- استخراج طبقه و واحد از آدرس، پیوند گوگل و مسیریابی؛ هیچ ادعای بررسی خودکار گوگل ندارد.
- برنامهٔ خرید ذخیره‌شده در مرورگر، دریافت فایل برنامه، متن آمادهٔ استعلام، پوستهٔ روشن و تیره.

## داده و کارایی

منبع رسمی: https://startech.s3.ir-central1.arvanstorage.ir/starcoach-dataset-v16-cap300-csv.zip?versionId=

تبدیل دوباره از CSVهای اصلی:

```sh
python scripts/import_dataset.py /path/to/extracted/csv
python scripts/verify_data.py
```

JSONها به‌صورت gzip از پیش فشرده و در پوشش JSON/base64 منتقل می‌شوند تا مدیر دانلود مرورگر آن‌ها را به‌جای درخواست داده نگیرد. چند آفر یک فروشنده برای یک محصول، در رابط به یک فروشگاه با کمترین قیمت منطبق تبدیل می‌شوند؛ عنوان گزینهٔ فروشنده جدا نمایش داده می‌شود. مرورگر مدرن با `DecompressionStream` آن‌ها را باز می‌کند. صفحهٔ اولیه فقط فروشگاه‌ها و ۲۴ محصول منتخب را می‌خواند؛ ایندکس کامل هنگام جستجوی سراسری و قطعهٔ جزئیات هنگام نیاز بارگیری می‌شود. تصاویر از URLهای اصلی دیتاست نمایش داده می‌شوند و به دسترسی image.torob.com وابسته‌اند. فونت Vazirmatn به‌صورت محلی همراه مجوز OFL ارائه شده و Tahoma جایگزین دارد.

## اتصال مدل زبانی

نسخهٔ static منتشرشده، راهنمای ساختاریافته دارد و مدل زبانی آنلاین به آن متصل نیست. سرور Node مسیر `/api/assistant` را دارد. فایل `.env.example` فهرست تنظیمات را مشخص می‌کند؛ مقدارها را در محیط میزبانی قرار دهید. `AI_BASE_URL` باید URL HTTPS یک API سازگار با Chat Completions باشد، بدون پسوند `/chat/completions`. `AI_API_KEY` و `AI_MODEL` لازم‌اند. برای بارگیری فایل محیط محلی می‌توانید `node --env-file=.env server.mjs` اجرا کنید.

مدل تنها با محصولات بازیابی‌شده و مشخصات ثبت‌شده پاسخ می‌دهد؛ خروجی مدل مشورتی است و موجودی یا تماس را تأیید نمی‌کند. بدون تنظیمات یا در شکست سرویس، fallback شفاف برمی‌گردد. متن نیاز کاربر در حالت متصل به ارائه‌دهندهٔ مدل ارسال می‌شود. کلیدها هرگز وارد فایل‌های `dist` نمی‌شوند.

## تماس واقعی: مرز اتصال و محدودیت

طبق صفحهٔ چالش، **تمام شماره‌های دیتاست جعلی‌اند**. بنابراین تماس خودکار به آن‌ها مسدود است. نام سرویس تماس در درخواست اولیه مبهم بود و کلید/مستندات سرویس ارائه نشده است؛ اتصال vendor مشخصی ادعا نمی‌شود.

سرور یک قرارداد adapter دارد تا سرویس تماس انتخابی بدون تغییر رابط داده متصل شود. POST به `/api/call` فقط با `Authorization: Bearer CALL_ADMIN_TOKEN` (بیش از ۲۰ کاراکتر)، شمارهٔ واقعی اپراتور-تأییدشده و وجود آفر واقعی محصول/فروشگاه پذیرفته می‌شود:

```json
{"phone":"+98XXXXXXXXXX","contactSource":"operator_verified","productId":"product_...","shopId":"shop_...","requestId":"unique-request-id"}
```

`CALL_ADAPTER_URL` یک endpoint متعلق به شماست که به سرویس تماس واقعی ترجمه می‌کند. ورودی: `phone, shopId, productId, productTitle, questions, idempotencyKey`. خروجی مورد انتظار: `{ "requestId": "provider-request-id" }`. فقط ثبت درخواست برمی‌گردد و `stockConfirmed:false` باقی می‌ماند. این نسخه webhook دریافت و تصدیق نتیجهٔ تماس ندارد؛ برای تولید، احراز اصالت callback، ذخیرهٔ نتیجه و سیاست انقضای تأیید لازم است. هیچ شمارهٔ واقعی را در مخزن قرار ندهید.

## استقرار در لیارا

`Dockerfile` و `liara.json` آماده‌اند. از داشبورد لیارا برنامهٔ Docker بسازید، سورس همین پوشه را deploy کنید و پورت ۳۰۰۰ را تعیین کنید. یا با CLI رسمی و حساب خودتان از همین پوشه `liara deploy` اجرا کنید. فایل‌های داده باید در بسته بمانند. تنظیمات حساس را در متغیرهای محیطی لیارا وارد کنید. استقرار لیارا در این جلسه انجام نشده، چون دسترسی حساب/برنامه در اختیار نبود. نسخهٔ میزبانی‌شدهٔ Sites از `dist` استفاده می‌کند و endpointهای Node را اجرا نمی‌کند.

## آزمایش

```sh
npm run check
npm test
python scripts/verify_data.py
```

آزمایش‌ها بازیابی واقعی، بودجه، fallback بدون مدل، ممنوعیت تماس بدون احراز هویت، ورودی خراب و عدم سرو فایل‌های حساس را بررسی می‌کنند. بررسی مرورگر جداگانه در Edge انجام می‌شود. این تست‌ها اتصال به سرویس خارجی را تأیید نمی‌کنند.
