# جستجوی ایندکس‌شده

نسخهٔ عمومی بدون سرویس اضافی از inverted index در حافظه استفاده می‌کند. آداپتور Elasticsearch برای سرویس موجود قابل تنظیم است؛ اگر آن سرویس قطع شود یا بیش از دو ثانیه پاسخ ندهد، جستجو به ایندکس داخلی برمی‌گردد و اتصال مجدد سی ثانیه عقب می‌افتد.

## Elasticsearch محلی

```sh
bash scripts/elastic-local.sh start
ELASTICSEARCH_URL=http://127.0.0.1:9201 npm run index:elastic
ELASTICSEARCH_URL=http://127.0.0.1:9201 OSRM_BASE_URL=http://127.0.0.1:5001 PORT=3103 npm start
```

Docker باید در دسترس باشد. سرویس `9.5.5` با digest ثابت، پلن Basic، سقف ۱٫۵ گیگابایت حافظه و دو CPU اجرا می‌شود. شماره پورت ۹۲۰۱ فقط روی loopback است. احراز هویت این نمونهٔ محلی خاموش است؛ آن را روی اینترنت منتشر نکنید. نسخهٔ عمومی باید به سرویس دارای احراز هویت و شبکهٔ خصوصی متصل شود. قابلیت‌های ML و دانلود GeoIP فعال نیستند. داده در volume مستقل `torob-elastic-data` باقی می‌ماند. توقف: `bash scripts/elastic-local.sh stop`.

۲۲۵٬۹۰۳ محصول واقعی دیتاست نسخهٔ ۱۶ وارد ایندکس محلی شدند. واردکننده دسته‌های ۵۰۰تایی می‌فرستد؛ refresh در زمان واردکردن متوقف و پس از پایان فعال می‌شود. شمارش اسناد پیش از جابه‌جایی اتمیک alias بررسی می‌شود؛ ایندکس قبلی برای بازگشت حفظ می‌شود. فقط نام محصول، دسته، شناسه، قیمت و شمارهٔ shard وارد Elasticsearch می‌شوند، نه گزارش‌های خصوصی کاربران.

برای سرویس موجود، `ELASTICSEARCH_URL` و در صورت نیاز `ELASTICSEARCH_API_KEY` را فقط در محیط سرور تنظیم کنید. راه‌اندازی محلی، سرویس پولی جدیدی در Liara ایجاد نمی‌کند.

منبع راه‌اندازی: [مستندات رسمی Docker در Elastic](https://www.elastic.co/docs/deploy-manage/deploy/self-managed/install-elasticsearch-docker-basic).
