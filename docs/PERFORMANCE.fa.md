# اندازه‌گیری سرعت — ۲۳ اکتبر ۲۰۲۶

اعداد اندازه‌گیری زیر مربوط به نسخهٔ پیش از بازیابی همهٔ مشخصات و تصاویر، دیتاست v16 و سناریوهای مشخص هستند؛ زمان اینترنت کاربر یا تضمین بار همزمان نیستند.

- در کانتینر با ۰٫۵ CPU و ۵۱۲ MB RAM، آماده‌سازی جستجو از ۱۰٫۱۰۲ ثانیه به ۳٫۴۰۲ ثانیه رسید. snapshot شاخص معکوس در زمان ساخت image تولید و با SHA-256 فایل‌های منبع اعتبارسنجی می‌شود.
- برای ۲۴ گوشی نمونه، روش قبلی ۹۰۳٬۵۵۵ بایت shard می‌فرستاد؛ API جدید ۱۶٬۱۵۹ بایت gzip فرستاد (حدود ۹۸٫۲٪ کاهش). برای ۲۴ کفش نمونه حدود ۱٫۰۳ MB به ۴٬۹۶۲ بایت رسید.
- در مرورگر Edge محلی با Elasticsearch آماده، نمایش اولین ۲۴ کارت در آزمون ۱۴۴۰ و ۳۹۰ پیکسل حدود ۰٫۱ تا ۰٫۳ ثانیه پس از ارسال جستجو طول کشید. این عدد شامل شروع سرد سرور عمومی نیست.
- جریان جستجو، نمایش بیشتر، انتخاب دقیق مدل‌ها برای AI، چک‌لیست فروشگاه و برگشت به نتایج در هر دو عرض بررسی شد. هیچ فایل index یا shard کامل محصول در این جریان به مرورگر ارسال نشد.
- یک درخواست واقعی به `anthropic/claude-haiku-5.5` از طریق لیارا پس از تنظیم بودجهٔ خروجی حدود ۲٫۷ ثانیه طول کشید و پاسخ ساختاریافته داد. زمان مدل متغیر است. سقف روزانه، فاصلهٔ درخواست‌ها و کش پایدار یک‌ساعته مانع مصرف بی‌حد می‌شوند.

## بازتولید بررسی‌های سرور

`npm run check`، `npm run test:unit` و `npm test` بررسی‌های کد، شاخص، قرارداد API، محدودیت داده، مقایسه و کنترل مصرف را اجرا می‌کنند. تست‌های دیتاست به فایل‌های محلی `dist/data` نیاز دارند.

در build داکر، `node --max-old-space-size=320 search-index.mjs --build` snapshot را تولید می‌کند. فایل `.cache` در سورس منتشر نمی‌شود؛ داخل image ساخته می‌شود. در نبود snapshot معتبر، شاخص از دیتاست ساخته می‌شود.

## Lazy Loading و صفحه‌بندی

صفحهٔ آغاز دادهٔ فروشگاه‌ها، محصولات و ماژول‌های نقشه، AI و چک‌لیست را درخواست نمی‌کند. جستجو ۲۴ نتیجه می‌گیرد و دکمهٔ نمایش بیشتر صفحهٔ بعدی را درخواست می‌کند. جزئیات حداکثر ۲۴ محصول از API گرفته می‌شود؛ گالری تصویر، ماژول‌های تعاملی و Leaflet هنگام استفاده بارگذاری می‌شوند.

با حفظ همهٔ فیلدهای موجود منبع، حجم مجموعهٔ خروجی داده از حدود ۷۷٫۶ به ۹۳٫۳ MB رسیده است. این فایل‌ها یکجا به مرورگر فرستاده نمی‌شوند. اعداد سرعت بالا به نسخهٔ قبلی تعلق دارند و تضمین عملکرد نسخهٔ جدید یا بار هم‌زمان نیستند.
