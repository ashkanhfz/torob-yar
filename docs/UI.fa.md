# بازطراحی رابط فارسی

رابط با زبان بصری ترب، زمینهٔ ساده، قرمز محدود به کنش‌های مهم، نوار جستجوی روشن و کارت‌های محصول بازطراحی شده است. این پروژه نمونهٔ مستقل است؛ فونت یا دارایی اختصاصی ترب بازنشر نشده است.

## تغییرهای اجراشده

- فونت محلی Vazirmatn Variable با وزن‌های واقعی ۱۰۰ تا ۹۰۰ و مجوز OFL؛ فایل قبلی تنها وزن معمولی داشت.
- تفکیک وزن و اندازهٔ عنوان، قیمت، توضیح و دادهٔ کمکی؛ خوانایی بهتر اعداد و قیمت‌ها.
- مجموعهٔ آیکون‌های SVG هماهنگ برای جستجو، موقعیت، مقایسه، علاقه‌مندی و راهنما.
- نوار جستجوی ثابت، جستجوهای پیشنهادی و کاهش متن‌های فنی در مسیر اصلی.
- فیلتر جمع‌شونده در موبایل، `aria-expanded` مطابق وضعیت و بسته‌شدن بعد از اعمال.
- دسترسی مستقیم برنامهٔ خرید در هدر موبایل.
- طراحی یکدست صفحهٔ محصول، فروشگاه‌ها، جدول مقایسه و پنجره‌های گفتگو.
- پوستهٔ تیره، focus قابل مشاهده، کنترل کاهش حرکت و عنوان دسترس‌پذیر مقایسهٔ هر محصول.

## بررسی انجام‌شده

Chrome دسکتاپ و اندازهٔ ۳۹۰×۸۴۴ بررسی شدند. در اندازهٔ موبایل، عرض صفحه از عرض قابل استفاده بیشتر نبود و شبکهٔ محصولات دو ستون داشت. باز/بسته‌شدن فیلتر و اعمال آن در مرورگر بررسی شد. این بررسی جای آزمون با کاربران واقعی را نمی‌گیرد.
