# استقرار روی لیارا

برنامه: `torob-yar-next-1023`

آدرس: https://torob-yar-next-1023.liara.run

- پلتفرم Docker، Node.js 22، پورت 3000؛ بدون وابستگی npm در زمان اجرا.
- پلن `small-g2` با 512 مگابایت رم و امکانات `basic`.
- فایل‌های دادهٔ تولیدشده در `dist/data` باید پیش از انتشار موجود باشند. این فایل‌ها در گیت نیستند؛ مراحل تولید در README آمده است.
- `.liaraignore` عمداً داده‌های آماده را نگه می‌دارد و فایل‌های خصوصی و داده‌های خام را حذف می‌کند. از تغییر آن به قواعد `.gitignore` خودداری کنید.
- توکن لیارا فقط در محیط محلی استفاده می‌شود؛ برنامه برای اجرا به آن نیاز ندارد.

پس از ورود به CLI در حساب و تیم مناسب:

```sh
liara deploy --no-app-logs
```

بررسی پس از انتشار:

```sh
curl --fail https://torob-yar-next-1023.liara.run/api/health
curl --fail 'https://torob-yar-next-1023.liara.run/api/search?q=samsung'
```

قابلیت مدل زبانی فقط با متغیرهای مستندشده در `.env.example` فعال می‌شود. در نبود آن‌ها راهنمای ساختاریافته کار می‌کند. قیمت‌ها تاریخی‌اند و موجودی فروشگاه‌ها به صورت زنده تأیید نشده است.
