## سه سناریوی مرزی برای تست دستی

### موجودی نامعلوم و قیمت قدیمی

با یک محصول دارای قیمت تاریخی شروع کن. کاربر نباید آن را «موجودی قطعی» بفهمد. یادداشت «پاسخ نداد» ثبت کن؛ نباید badge تأیید موجودی ظاهر شود.

### شکست فروشگاه با شرط اعتبار

اعتبار حضوری را فعال کن و فروشگاه اول را کنار بگذار. هر جایگزین باید همان شرط را داشته باشد. اگر گزینه‌ای نیست، نتیجهٔ خالی از نمایش فروشگاه غیرمنطبق بهتر است.

### فقدان مجوز موقعیت

GPS را رد کن و محله را دستی انتخاب کن. جستجو و مقایسه همچنان قابل استفاده باشند. هیچ موقعیت مخفیانه‌ای از مرورگر خوانده نشود.
